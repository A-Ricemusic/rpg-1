For this project please use typescript. For more information here is the documentation: https://roblox-ts.com/docs/ also the github repository is here: https://github.com/roblox-ts/roblox-ts

For package management please use bun exclusivly. Please do not use NPM

We are using rojo to sync code thus code must be kept in the correct directories to sync properly Please review the rojo documentation if you have any questions: https://rojo.space/docs/v7/

Blender is avaiable on this computer plese use it for asset creation if insturcted.

The Roblox mcp server also allows you to interact with roblox studio Please use it when needed.

When ever finishing code changes please run a formatting command, a type check command, as well as lint commands. 

bun run format
bun run typecheck
bun run lint


Please avoid the use of type ANY. You may only use it when given explict permissions.

For frontend components we prefer the use of roact. Use function componenets over class componenets when possible.
