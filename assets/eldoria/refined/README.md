# Refined Eldoria Blender library

31 Blender models are now present in Studio as 84 source MeshParts (103,010 triangles), with copies in all five regions and usable equipment and character templates.

Open Eldoria-refined-library.blend and Moonblade-pilot.blend for editable sources. FBX exports and geometry JSON preserve evaluated meshes. Studio-sanctuary.png and Studio-temple.png are actual Studio captures; other previews are Blender renders.

See HANDOFF-v2.md and docs/handoffs/world.md for import evidence, instance paths and persistence limitations. Manual Studio Save As and reopen verification remain required. Transfer helpers are edit-time only, outside Rojo gameplay directories. Acquire the shared lock before Studio operations.
